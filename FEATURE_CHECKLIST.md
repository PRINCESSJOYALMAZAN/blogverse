# BlogVerse Feature Checklist

- Flutter app uses Provider for state management.
- Flutter app uses go_router for routing.
- Supabase is used for authentication, database rows, and image storage.
- Registration uses email and password only, with no confirm password field.
- Login and logout are implemented.
- Feed is public and paginated.
- Posts support create, view, update, delete, and multiple images.
- Comments support create, view, update, delete, and multiple images on each post.
- Profile supports display name updates and profile photo upload/delete.

Disable email confirmation in Supabase Auth settings for direct registration-to-dashboard testing.
